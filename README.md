## 学んだこと
・マイグレーションの作成方法を知った。まだまだ分からないことの方が多く、とても難しく感じる。<br>
・シーダーやコントローラーを使って作ったが、ブラウザで確認すると中々表示されず困りごとが多かった。<br>
・クエリビルダーがどういったものかわからず、AIに聞いたりなどした。<br>
・全体的に終始詰まっていた。どこにどのコードを書くといったことを理解できるように努力したい。
